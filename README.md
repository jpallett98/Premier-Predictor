# Premier Predictor v2

A substantially expanded mobile-first prototype.

Includes:
- Home dashboard
- Gameweek 1 with all 10 official fixtures currently listed
- Home/draw/away prediction controls
- Season prediction form for the 10 agreed categories
- 110 season points available
- Leaderboard
- League members + invite code
- Profile/scoring rules
- Local in-browser state for selections
- PWA manifest/service worker

Production work still needed:
- Secure authentication
- Cloud database and multiplayer sync
- Server-side prediction locking
- Live fixture/result/player-stat data
- Automatic scoring
- Push notifications
- Admin console
- Real-money payments/payouts only after appropriate UK legal review

The fixture examples use the official 2026/27 Matchweek 1 list published by the Premier League. The Premier League notes that fixtures can change, so production must sync updated fixture data.
