# FanRank V14

V14 adds real shared leagues using Supabase.

## Before testing
1. Keep the V13 `profiles` schema already installed.
2. Run `fanrank-v14-leagues-schema.sql` in the Supabase SQL Editor.
3. Upload V14 files to GitHub Pages.
4. Log in to FanRank.
5. Create a league and confirm it appears in Supabase.
6. Use another account/device to join using the invite code.

The league tables are protected by Row Level Security. Never add a Supabase secret/service-role key to the browser or GitHub.
